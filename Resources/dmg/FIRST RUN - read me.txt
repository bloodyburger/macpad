MacPad: first launch

This build is signed but NOT notarized by Apple, so macOS refuses to open it
on the first try and says it cannot verify the app. That is macOS checking an
unverified download, not a broken app.

To open it:

  1. Drag MacPad.app to your Applications folder.
  2. Double-click MacPad. macOS shows a warning. Click Done.
  3. Open System Settings, go to Privacy & Security, scroll down to the
     message about MacPad, and click Open Anyway. Confirm when asked.

On macOS 13 and 14 there is a shorter way: right-click (or Control-click)
MacPad.app, choose Open, then click Open in the dialog.

Only the first launch needs this. If neither way works, run this in Terminal:

  xattr -dr com.apple.quarantine /Applications/MacPad.app

If you open MacPad from this disk image instead of dragging it, MacPad says
so and offers to move itself to Applications for you. Once it runs from
Applications, it ejects any MacPad disk images that are still open. Each
image is named after its version, so you can tell them apart.

What to expect in this build: tabs, syntax highlighting, find and replace
with Perl-syntax regular expressions, encodings, line endings, and sessions
that come back after every launch. See docs/FEATURES.md in the repository
for what is and is not done.
