MacPad 0.1.1 is a small release that changes how MacPad describes and publishes itself; the editor behaves as in 0.1.0.

- MacPad now presents itself as what it is: a native text and code editor for macOS. The in-app About and Help text, the read-me in the disk image and all documentation are rewritten to match.
- The session file has MacPad's own format name. Session files written by 0.1.0 still load, so your open tabs and unsaved text carry over.
- Releases are now published automatically for every build of the main branch, with the version number set by the build, so the app's version and its release can never disagree.
- The feature list is at `docs/FEATURES.md`, and the plan at `docs/PLAN.md`.

**Installing**

Open the disk image, drag MacPad to Applications, then right-click it and choose Open the first time. The build is signed but not notarised, so macOS asks once.

Universal binary for Apple silicon and Intel. Free software under the GNU GPL v3 or later.
