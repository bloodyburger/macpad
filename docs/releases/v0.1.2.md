MacPad 0.1.2 adds a right-click menu and more editing commands, and fixes the clipboard shortcuts in the find bar.

**New**

- Right-click in the editor for Cut, Copy, Paste, Delete, Select All, UPPERCASE, lowercase, Toggle Line Comment, Block Comment, Block Uncomment, Find Selection, Search with Google and Toggle Bookmark.
- Edit menu: Delete, Convert Case (UPPERCASE with Shift-Command-U, lowercase with Command-U), Block Comment (Option-Command-/) and Block Uncomment.
- Menu items are greyed out when they would do nothing, such as Toggle Line Comment in a plain-text tab, and the Line Endings, Language and Encoding menus tick the current choice.

**Fixed**

- With the cursor in the find or replace field, Paste, Copy, Cut, Select All and Undo now act on that field. Before, Command-V in the find field pasted into the document.

**Tip:** comment commands follow the tab's language. A new tab is plain text; pick a language from the Language menu, or save the file with an extension, and Command-/ comments the current line.

**Installing**

Open the disk image, drag MacPad to Applications, then right-click it and choose Open the first time. The build is signed but not notarised, so macOS asks once.
